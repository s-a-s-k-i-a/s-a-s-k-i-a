# Google Sans

The regular and bold TTF files in this directory are static 400 and 700 weight
instances of `GoogleSans-Latin.woff2` from the current Isla Studio website.
They were generated with fonttools 4.59.2 so that the profile card renders the
same typography byte-for-byte on macOS and GitHub's Linux runners.

The website source font was obtained on 4 August 2026 through the official
Google Fonts CSS API:

`https://fonts.googleapis.com/css2?family=Google+Sans:ital,wght@0,400;0,500;0,600;0,700;1,400&display=swap`

Google Sans is distributed under the SIL Open Font License. The license text is
included as `OFL.txt`. The two instances are bundled locally; rendering does not
contact Google Fonts.
